# ChromaFind

ChromaFind is a modern image-search application designed to let users explore the world in vibrant color. In its final form, it will fetch and display images in a responsive grid based on user search queries. 

**Design Decisions:**
1. **Teal & Slate Color Palette:** I chose a teal (`#0d9488`) primary color combined with a slate grey text scheme to give the app a fresh, modern, and trustworthy aesthetic that differs distinctly from the reference's purple theme.
2. **Category Chips & Empty State:** I included a quick-pick category row so users can execute common searches with one click, and implemented a visual empty state ("Search to see results") with an icon to guide the user naturally when they first land on the page or clear their search.
